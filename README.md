## 📌 About the Project

The **GPA & CGPA Calculator** is a web-based application designed to help college students calculate their Grade Point Average (GPA) and Cumulative Grade Point Average (CGPA) easily and accurately.

Students can enter their subject credits and grades to calculate their academic performance. The application also supports generating a report for downloading or printing.

## ✨ Features

* 📊 Calculate semester GPA.
* 🎓 Calculate cumulative CGPA using credit-weighted results.
* 📚 Enter subject credits and grades.
* 🧮 Automatically calculate grade points.
* 📄 Generate an academic performance report.
* 🖨️ Print or download the report.
* 📱 Simple and user-friendly interface.

## 🛠️ Technologies Used

* **HTML5** – Webpage structure.
* **CSS3** – Styling and responsive design.
* **JavaScript** – GPA and CGPA calculations and interactive functionality.

## 📐 Calculation Formula

**GPA Formula**

GPA is calculated using the credits and grade points of subjects in a semester.

`GPA = Σ(Credits × Grade Points) / Σ(Credits)`

**CGPA Formula**

CGPA is calculated using the total credit-weighted grade points across all included semesters.

`CGPA = Total Credit-Weighted Grade Points / Total Credits`
